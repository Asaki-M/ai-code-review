# SQL / 数据库 Code Review 规范

## 查询正确性
- 检查 JOIN 条件、过滤条件、聚合口径、NULL 语义、排序稳定性和分页一致性。
- 涉及金额、库存、状态流转和统计口径时，确认事务和隔离级别是否满足要求。
- 避免隐式类型转换、时区误差、大小写/排序规则差异导致的结果错误。

## 性能
- 检查 WHERE、JOIN、ORDER BY、GROUP BY 是否能利用合适索引。
- 避免 SELECT *、深分页、大范围锁表、全表扫描和在索引列上使用不可索引函数。
- 大批量写入、迁移或回填应分批执行，并说明回滚方案。

## 安全
- 所有用户输入必须参数化，禁止字符串拼接 SQL。
- 检查 SQL 注入、越权查询、跨租户数据泄漏和敏感字段暴露。

## Schema 变更
- 新增非空列、唯一索引、字段类型变更、表重命名等需考虑线上兼容和迁移顺序。
- 索引变更应评估写入放大、锁影响、回滚成本和灰度发布策略。
