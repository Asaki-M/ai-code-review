# 后端 Code Review 规范

## API 与业务正确性
- 检查接口入参校验、鉴权、权限边界、租户隔离和资源归属校验。
- 检查幂等性、事务边界、并发更新、重试机制和错误码语义。
- 检查向后兼容性，包括响应字段、枚举值、默认行为和版本迁移。

## 安全
- 检查认证绕过、越权访问、SSRF、路径穿越、命令注入、反序列化风险。
- 密钥、token、个人信息和业务敏感数据不得出现在日志或错误响应中。
- 外部输入进入命令、文件路径、SQL、模板或 URL 前必须经过约束和校验。

## 可靠性
- 检查超时、限流、熔断、降级、重试退避和外部依赖失败处理。
- 后台任务、消息消费和 webhook 应考虑重复投递、乱序和部分失败。
- 关键路径应有必要日志、指标和追踪信息，避免噪声日志。

## 性能
- 关注 N+1 查询、无界循环、无界分页、同步阻塞和大对象内存占用。
- 检查缓存键、失效策略、一致性要求和缓存穿透风险。
